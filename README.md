Instrucciones de Compilación
1. Clonar el repositorio.
2. Abrir el proyecto en un IDE compatible con C++ (Zinjal, Dev-C++, Visual Studio).
3. Asegurarse de que todos los archivos `.h` y `.cpp` estén agregados al proyecto.
4. Compilar y ejecutar. Los archivos `.txt` (empleados, departamentos, planilla) se crearán automáticamente en la carpeta del ejecutable al guardar datos.

Guía de Uso
1. Al iniciar, el sistema cargará los datos previos de los archivos `.txt`.
2. Seleccione la opción 1 para registrar un empleado (Médico, Enfermero o Administrativo).
3. Seleccione la opción 4 para crear departamentos y agregarles puestos.
4. Seleccione la opción 5 para procesar el pago de un empleado en un departamento específico.
5. Todos los cambios se guardan automáticamente en los archivos de texto.
